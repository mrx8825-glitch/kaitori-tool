💡 【将来的なシェア用】Node.jsローカルサーバー案（クリックで展開） ▼
marlabブラックで共有する場合や、本格的に使う場合はNode.jsサーバーを挟むことでClient Secretを安全に管理できます。
以下のコードをローカルで実行して http://localhost:3001 にアクセスしてください。
// server.js — npm install express cors node-fetch const express = require('express'); const cors = require('cors'); const fetch = require('node-fetch'); const app = express(); app.use(cors({ origin: 'null' })); // HTMLファイルはorigin:nullで動く app.use(express.json()); const EBAY_APP_ID = process.env.EBAY_APP_ID || 'YOUR_APP_ID'; const EBAY_CERT_ID = process.env.EBAY_CERT_ID || 'YOUR_CERT_ID'; // GET /ebay/token → eBayトークン取得 app.get('/ebay/token', async (req, res) => { const cred = Buffer.from(`${EBAY_APP_ID}:${EBAY_CERT_ID}`).toString('base64'); const r = await fetch('https://api.ebay.com/identity/v1/oauth2/token', { method: 'POST', headers: { Authorization: `Basic ${cred}`, 'Content-Type': 'application/x-www-form-urlencoded', }, body: 'grant_type=client_credentials&scope=https%3A%2F%2Fapi.ebay.com%2Foauth%2Fapi_scope', }); const data = await r.json(); res.json(data); }); // GET /ebay/search?gtin=xxx&marketplace=EBAY_US app.get('/ebay/search', async (req, res) => { const { gtin, q, marketplace = 'EBAY_US' } = req.query; const tokenRes = await fetch('http://localhost:3001/ebay/token'); const { access_token } = await tokenRes.json(); const searchUrl = gtin ? `https://api.ebay.com/buy/browse/v1/item_summary/search?gtin=${gtin}&limit=10` : `https://api.ebay.com/buy/browse/v1/item_summary/search?q=${encodeURIComponent(q)}&limit=10`; const r = await fetch(searchUrl, { headers: { Authorization: `Bearer ${access_token}`, 'X-EBAY-C-MARKETPLACE-ID': marketplace, }, }); const data = await r.json(); res.json(data); }); app.listen(3001, () => console.log('eBay proxy running on http://localhost:3001')); // 起動: node server.js // HTMLからのeBay検索先を http://localhost:3001/ebay/search?gtin=xxx に変更

📋 仕様・STEP4 eBay API詳細・計算式（クリックで展開）
▸ STEP4 機能（eBay Browse API）
・楽天で選択した商品のJANコードをGTINとしてeBay Browse APIで検索
・エンドポイント: /buy/browse/v1/item_summary/search?gtin={JAN}
・商品名・価格・通貨・送料・状態・URL・出品国・itemIdを表示
・JANコードなしの場合は商品名でフォールバック検索
・トークン期限切れ(2時間)で自動的にエラー表示 → 再取得を促す
▸ eBay OAuth / CORS について
A. ブラウザ直接（HTML単体）
　- Browse API自体はBearerトークン付きでCORS通過可能
　- トークン取得エンドポイント（/identity/v1/oauth2/token）はCORS非対応
　- 対策：curlで手動取得 → 手動ペースト（有効期限2時間）

B. Node.jsローカルサーバー（将来的なシェア推奨）
　- Client SecretをHTMLに含めず安全に管理
　- トークン自動更新が可能
　- 設定パネルのコードスニペット参照（server.js）
▸ 計算式
ポイント還元額 = 楽天価格 × ポイント還元率 ÷ 100
実質仕入価格 = 楽天価格 − ポイント還元額 + 送料・手数料
利益額 = 買取価格 − 実質仕入価格
利益率 = 利益額 ÷ 実質仕入価格 × 100
売価率 = 買取価格 ÷ 実質仕入価格 × 100
